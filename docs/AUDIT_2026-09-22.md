# TraceQ Arduino 2차 전체 로직 감사 — 2026-09-22 (v2.2.6 기준)

6개 영역(RFID / 업무 프로세서 / main·시리얼 / UI·NVM / 메모리·빌드 / PC 계약)을 나눠
정독하고, 올라온 P2 후보를 코드에서 직접 재확인했다. 이번에는 **AVR 시뮬레이터 행위 시험**
(`tools/sim/`)을 새로 만들어, 고친 결함마다 "수정 전 코드에서 빨강 → 수정 후 초록"을
실제 제품 코드로 확인하고, 수정을 하나씩 되돌린 변이 12개가 모두 해당 시험만 빨강이 되는지
(음성대조) 확인했다. 와이어 바이트·태그 블록 맵·EEPROM 주소는 바꾸지 않았다.

## 사용자 결정 (09-23 전부 결정·반영)
1. 액교환일 방전 표지 → "시계가 복구될 때 기록".
2. 검사명 15바이트 절단 → SeePro 는 15바이트로 자르고(깔려 있는 옛 리더기에도 바로 듣는다),
   **펌웨어는 블록 16바이트를 다 담게** 고쳤다(`data[17]`) — 올눈은 16바이트 조각으로 보내므로 그 현장은 이쪽이 필요했다.
   받는 쪽 확인: 세척관리(TraceQ_Python)는 블록마다 cp949 로 풀고 뒤 NUL 만 떼므로 NUL 없는 16바이트도 정상(`parse_examination_subjects`).
3. 올눈 게이트웨이 현장 있음 → 게이트웨이 수신 1초.
4. 세척기 더블터치 방지 → 소독기와 같게.
